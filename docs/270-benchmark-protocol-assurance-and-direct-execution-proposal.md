None of these inspected descriptions establishes that arbitrary files are cuts
from one long recording. Equally, they do not prove that every released file has
independent capture/content ancestry. Replay attacks deliberately record displayed
source material; different camera recordings can share that material. Therefore
the useful conclusion is **follow the documented benchmark unit and partition**,
not either "all clips are unrelated" or "suspected similarity invalidates the
entire benchmark."

This explicitly accepts an assurance limitation. It is not implied by widespread
dataset use or by the owner's belief about how videos were collected. If the
scientific decision rejects that limitation, this proposal does not unblock the
study; no further image tier or model switch follows automatically.

The five witnesses cannot be dismissed from general collection descriptions.

decisions retain their accepted scope. Unknown cross-dataset participant/content

not newly verified absences. The conditional claim is performance under the
declared released-data protocol, not generalization to proven independent capture
events. This dependence can bias results and uncertainty intervals; conventional
grouping does not remove that risk.

## Direct Sequence After That Decision

1. **Adopt once, then implement the exact policy.** Add a separately named
   documented-benchmark eligibility record and consuming gate; never set the old
   lineage result to passed or bypass its failing field. Bind the adopted text,
   source references, frozen populations and the existing264/268 commitments.
   Preserve all historical records. No separate activation/acknowledgment review.
2. **Close operational intake in one four-dataset batch.** Reuse completed
   adapters, hashes, membership and role checks. Run only missing discriminating
   checks: declared subject/video boundary integrity, protocol membership, exact
   prohibited overlap, labels, availability and deterministic terminal failures.
   Report actual per-dataset blockers once; no new all-pairs content search,
   SSCD, controls collection, provider contact or repeated unchanged full suite.
   A previously confirmed hard failure cannot be waived by the new policy.
3. **Complete deterministic preprocessing and one source-only smoke package.**
   Use the already specified frame selector, face/context geometry and terminal

   source or synthetic inputs, with a predeclared resource cap. No target scores
   for tuning and no silent detector-success replacement. This is downstream
   work, not evidence retrospectively resolving the399 ledger.
4. **Freeze the complete analysis once.** Close the other outstanding method,
   population, uncertainty and execution gates; check that the proposed claims
   match the actual grouping and conditional assurance. Then freeze the analysis
   before the first outer-target result. Conditional intake alone authorizes
   neither scientific readiness nor locked evaluation.
5. **Run the declared experiments and report results.** Apply the frozen method
   across the four targets; report failures, coverage, appropriate clustered
   uncertainty and the unresolved-ancestry limitation alongside performance.
   New concrete evidence of prohibited overlap stops the affected execution and
   requires explicit disposition, not post-result split repair.

Stages1-3 should form one bounded implementation/dry-run package after adoption,
